# Quiz App

A simple command-line quiz application built with Python.

## Description

This is a mini project that implements an interactive quiz game. Users are presented with multiple-choice questions and receive instant feedback on their answers. The application tracks and displays the final score at the end.

## Features

- Multiple-choice questions (A, B, C, D options)
- Instant feedback for each answer
- Score tracking
- General knowledge questions covering:
  - Geography
  - Mathematics
  - Science
  - Literature

## How to Run

1. Make sure you have Python installed on your system
2. Navigate to the project directory
3. Run the following command:

```bash
python main.py
```

## How to Play

1. Answer each question by entering the letter of your choice (A, B, C, or D)
2. Press Enter to submit your answer
3. You'll receive immediate feedback if your answer is correct or incorrect
4. After all questions are answered, your final score will be displayed

## Question Format

Each question includes:
- The question text
- Four multiple-choice options (A, B, C, D)
- The correct answer for validation

## Example

```
Q1: What is the capital of France?
A) Berlin
B) Madrid
C) Paris
D) Rome
Your answer(A/B/C/D): C
Correct!

Your final score is 1/4
```
